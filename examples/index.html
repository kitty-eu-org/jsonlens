@jsonlens

同一个内核，四种接法 —— 渲染、交互、性能完全一致

原生 JS

createExplorer(el) —— 零框架，最底层

React 18

<JsonExplorer value={text} />

Vue 3

<JsonExplorer :value="text" />

Web Component

<json-explorer src="…"> —— 一行标签

分层

内核只认 DOM，不认框架。框架层各自 60~120 行，只把「挂载 / 卸载 / 属性变化」翻译成 createExplorer / load / destroy。

包 作用 谁该用
@jsonlens/core 查看器本体 + 引擎层（零依赖） 任何场景，包括自己搭 UI
@jsonlens/react React 组件（forwardRef） React 17+
@jsonlens/vue Vue 组件（render 函数，无需 SFC 编译） Vue 3
@jsonlens/element <json-explorer> 自定义元素 服务端模板 / 任意框架 / 无构建
@jsonlens/svelte Svelte action：use:jsonExplorer Svelte 3/4/5

每个页面都有「小文件 / 24 MB / 展开 3 层 / 非法 JSON / 主题」几个按钮，可以横向对比同一份数据在不同接法下的表现。
